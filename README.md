## About the Music

All lyrics and musical concepts in this repository are original works written by the creator. The audio tracks were developed using a hybrid production process:
* **Lyrics & Concepts:** 100% original human authorship.
* **Audio Generation:** Created using AI music generation tools.
* **Arrangement & Editing:** Multitrack editing, vocal adjustments, and final mixing completed in Audacity.

The purpose of this site is simply to share original songs for listeners to stream and enjoy.
